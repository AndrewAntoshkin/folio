design-system-ai-starter

Превращает живую дизайн-систему в спеки, которым агент может следовать. Понимает CSS-переменные, JSON-токены и формат DTCG.

Проблема

Агенты хорошо пишут реализацию и плохо держат цельность. Обычно они:

  • Выдумывают значенияСтавят 12px вместо шага вашей шкалы или правдоподобный синий вместо семантического цвета ссылки
  • Пропускают композициюЗнают API компонента, но не знают, когда и как компоненты собирать вместе
  • Теряют контекстПлывут между сессиями: каждый разговор начинается с нуля
  • Что делает инструментКладёт в репозиторий устойчивый источник правды, который агент читает локально

Установка

Запускается через npx или ставится глобально.

npx design-system-ai-starter init .

Быстрый старт

Три команды от пустого проекта до спеки, которую читает агент:

# 1. Scaffold the structure
npx design-system-ai-starter init .

# 2. Sync your real tokens
npx design-system-ai-starter sync-tokens \
  --input ./tokens.css --target .

# 3. Verify everything is in place
npx design-system-ai-starter doctor .

Кому это

  • Команды дизайн-системУже есть токены или тема, которые агент должен соблюдать
  • Фронтенд-команды с AICursor, Claude Code, Copilot — любой агент, который пишет интерфейс
  • Продуктовые командыХотят, чтобы AI перестал выдумывать цвета, отступы и поведение компонентов

Команды

init

Раскладывает в существующем проекте структуру, которую читает агент.

npx design-system-ai-starter init .
ФайлНазначение
.cursor/rules/design-system.mdcПравило агента Cursor
CLAUDE.design-system.mdИнструкция для Claude Code
AGENTS.design-system.mdОбщая инструкция для агента
specs/foundations/*.mdЦвет, отступы, типографика, скругление, движение
specs/tokens/token-reference.mdПолный список токенов
specs/components/_template.mdШаблон спеки компонента

sync-tokens

Читает настоящий источник токенов и обновляет markdown-спеки.

npx design-system-ai-starter sync-tokens \
  --input ./tokens.css --target .
ФлагОписание
--input <file>Путь к CSS или JSON с токенами
--target <dir>Папка проекта со specs/

doctor

Проверяет, что все файлы для агента на месте и заполнены.

npx design-system-ai-starter doctor .
OK Cursor rule: .cursor/rules/design-system.mdc
OK Claude guide: CLAUDE.design-system.md
OK Token reference: specs/tokens/token-reference.md
OK Color foundation: specs/foundations/color.md
OK Spacing foundation: specs/foundations/spacing.md
OK Typography foundation: specs/foundations/typography.md

WARN No detected tokens in specs/foundations/motion.md
WARN No component specs found beyond the template

Doctor checks passed with 2 warning(s).

ФорматПример

Свой JSON{ "value": "#3b82f6", "type": "color" }
Массивы имя/значение[{ "name": "primary", "value": "#3b82f6" }]

До и после

Токены уже есть. Инструмент добавляет слой, который агент умеет читать.

До

app/
styles/
tokens.css ← your tokens exist
src/
components/ ← but agents can't read them

После

app/
.cursor/rules/design-system.mdc ← Cursor reads this
CLAUDE.design-system.md ← Claude reads this
AGENTS.design-system.md ← any agent reads this
specs/
foundations/
color.md ← 5 color tokens
spacing.md ← 6 spacing tokens
typography.md ← 6 typography tokens
tokens/
token-reference.md ← full token list
components/
_template.md ← fill per component

Пример CSS-токенов

Входной файл с CSS-переменными:

:root {
  --color-primary: #3b82f6;
  --color-secondary: #6366f1;
  --color-text: #0a0a0a;
  --color-bg: #fafafa;
  --color-muted: #737373;

  --spacing-xs: 4px;
  --spacing-sm: 8px;
  --spacing-md: 16px;
  --spacing-lg: 24px;
  --spacing-xl: 32px;
  --spacing-2xl: 48px;

  --font-size-sm: 0.875rem;
  --font-size-base: 1rem;
  --font-size-lg: 1.25rem;
  --font-size-xl: 1.5rem;
  --font-size-2xl: 2rem;
  --font-size-display: 3rem;
}

Команда sync-tokens собирает markdown с таблицами, категориями и форматом для агента.

Пример JSON-токенов

Файл токенов в формате DTCG:

{
  "color": {
    "primary": {
      "$value": "#3b82f6",
      "$type": "color"
    },
    "bg": {
      "$value": "#fafafa",
      "$type": "color"
    }
  },
  "spacing": {
    "sm": {
      "$value": "8px",
      "$type": "dimension"
    },
    "md": {
      "$value": "16px",
      "$type": "dimension"
    }
  }
}
