I don't stop at the mockup. I design the interface, write the rules — states, components, tokens — and take that through to code. If an agent assembles the interface later, it gets the same specification. Otherwise design, engineering, and the agent each build their own version.

I develop the Yandex HR Tech design system: components, tokens, documentation, and code. Alongside it I build tools that check whether an agent uses a system that already exists, instead of drawing its own.

From 2021 to 2025 I led design systems at Sber, from components to the rules for using them. Before that I designed products for private investors at Otkritie Broker and interfaces at MTS.

An agent often draws its own Button and hardcodes a color, because the system is not next to the task and nobody checks the result. The tools pack a short context, repair the interface onto the system, and measure whether the answer used its components.

The agent finds what the system already has, drafts, and runs the checks. I set the task, set the boundaries, and look at the result. The product decision, and anything that goes out under my name, stays with me.
