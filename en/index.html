I don't stop at the mockup: I map the flows, specify states and tokens, and carry the work into code. That gives design, engineering, and coding agents one shared source of truth instead of three competing interpretations.

I lead components, tokens, and documentation for the Yandex HR Tech design system. Alongside it, I build open-source tools around coding agents: context packing, static token/import checks, and the ds-eval benchmark.

Without explicit context and automated checks, an agent invents its own Button and hardcodes colors. The tools cover three steps: pack system rules under a token budget, lint imports and tokens in code, and diff prompt runs.

The agent drafts against the spec and runs the checks. Problem framing, product tradeoffs, system architecture, and sign-off on what ships to production stay with me.
