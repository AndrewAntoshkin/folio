Port an animation

Cursor skillSKILL.md + scriptsMIT

A Cursor skill that takes an animation you like from a site, video or gif and rebuilds it in my site's style: glass, soft gradients, a mint accent. It checks the timing frame by frame.

Download .zip

How it works

  1. Record. Opens the reference in headless Chromium and records frames, CSS and WAAPI animations, and where each element is on every frame. The source can be a site, a video, a gif or a Lottie file.
  2. Spec. Breaks the motion into a table: start, duration, stagger, easing. Next to each value it notes what that becomes on the site.
  3. Build. Writes plain HTML, CSS and a block in motion.js, using only tokens: --glass, --mint, --ease. A reduced motion fallback is required.
  4. Verify. Records the clone with the same command and compares the tracks. It keeps fixing until timings match within 80 ms, usually in 2 to 5 rounds.

Install

# 1. unzip into your project (or ~/.cursor/skills/ for every project)
unzip antoshkin-reanimate.zip -d .cursor/skills/

# 2. Bun 1.1+ and a one-time setup (~250 MB: Chromium + ffmpeg)
curl -fsSL https://bun.sh/install | bash
bash .cursor/skills/antoshkin-reanimate/scripts/setup.sh

# 3. keep the artifacts out of git
echo ".reanimate/" >> .gitignore

Then just ask the agent in Cursor: "port the card hover from https://… into the projects block".
