Intent OS

A Mercury interaction study for AI agents

This is a study interpreting the architecture and art direction of Jason Yuan’s Mercury OS, not an original operating-system concept. I adapted its Modules, Flows, Spaces, and Locus principles to my own agent-ui components and design-system tooling.

Traditional IDEs and desktop shells cram AI agents into a narrow chat sidebar. When an agent audits a design system, proposes a six-file token patch, or diffs two prompt runs, the human is forced to bounce manually between the chat thread, code editor, browser, and terminal.

In Intent OS, the primary unit of interface is not an application window or folder—it is the user's Intent. As soon as a task is stated, the workspace dynamically choreographs a three-module constellation (Locus):

  • Locus StreamLive Thinking, Tool Call, Approval, and Choice primitives from agent-ui surface model reasoning, static analysis matches, and explicit human-in-the-loop sign-off.
  • Live Artifact StageSynchronized component renderer with instant "Before Patch / DS Semantics" switching and live DOM token inspection.
  • Context & TelemetryA Context Meter ring, interactive Plan checklist, and real-time evaluation bars (DS Compliance, axe A11y, Token Drift).

Three interactive intents inside the prototype

Switch between three complete workflows using keys 1, 2, 3 or the floating command dock:

Intent ScenarioActive PrimitivesWhat It Verifies
1. Token RepairThinking · ToolCall (ds-lint) · ApprovalReplaces 6 hardcoded hex values and raw buttons in SettingsPage.tsx with semantic tokens after user approval.
2. Checkout AssemblyChoice · Plan · ArtifactClarifies container architecture (side Sheet vs centered Modal) and composes the flow with zero custom controls.
3. Prompt RegressionToolCall (prompt-regress) · AnswerChartDiffs system prompts v12 → v13 across 10 benchmark cases, showing a +34.1 pt jump in DS compliance.

Visual craft & token physics

  • Reactive ambient light field: a 60fps canvas shader shifts color temperature in sync with the active accent token (Mint, Iris, Amber, Sky);
  • Zero hardcoded palette classes: every primitive binds strictly to CSS variables, so flipping the theme swatch recolors charts, rings, and approvals simultaneously;
  • Built-in Spec X-Ray: holding Alt overlays live token badges directly across the spatial modules.
