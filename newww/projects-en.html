Projects

Tools and checks built around one problem: getting coding agents to use an existing design system instead of inventing their own controls.

Runs the same UI tasks through model outputs and measures whether a coding agent follows a design system it did not invent.

Tools

(4)

Components with Cursor rules and three npm CLIs: Figma-to-markdown specs, token linting, and import coverage.

agent-uiComponents

Components for chat and agent UIs, installed with Cursor rules.

figma-to-design-mdCLI

Extracts Figma variables and components into a markdown spec for agents.

ds-lintScanner

Finds hardcoded colors, spacing, and fonts and suggests a token instead.

ds-coverageScanner

Measures where the codebase imports the design system vs. rebuilds it.

Prototypes & utilities

(4)
ds-context

Packs a design system into a short context for the agent and estimates its size in tokens.

ui-repair

Replaces raw controls and hardcoded colors with system components.

prompt-regress

A diff of two runs after a prompt change: which cases improved and which ones broke.

ds-health

Paste a live URL and get a report on how many colors, type styles, spacings, and radii the page actually uses.
