# Agent skills

Portable instructions for design-engineering and AI-native design-system work. Copy an individual `SKILL.md` into an agent's skills directory.

- [Replace hardcoded values](token-map/SKILL.md) — Replaces hardcoded colors, spacing, and radii with design tokens.
- [Write DESIGN.md](design-md/SKILL.md) — Builds a short DESIGN.md that agents can follow.
- [Find duplicate components](component-adoption/SKILL.md) — Finds local copies of design-system components and swaps them back.
- [Review a screen](ui-review/SKILL.md) — Checks a screen at 390 and 1280 px, with keyboard and real data.
- [Document a component](component-docs/SKILL.md) — Documents a component from its real code and usage.
- [Move a screen to the design system](ds-migrate/SKILL.md) — Moves one screen to design-system components without changing behavior.
- [Check every state](ui-states/SKILL.md) — Renders every state of a component before you call it done.
- [Add animation](motion/SKILL.md) — Adds motion only where it helps, and respects reduced motion.
- [Check accessibility](a11y-pass/SKILL.md) — Checks contrast, focus, names, and readable type in the running UI.
- [Describe an action](interaction-spec/SKILL.md) — Writes down what happens on click, on error, and on cancel.
