Что считает

  • ЦветаСколько уникальных цветов текста и фона встретилось на странице и какая доля задана через CSS-переменные.
  • ТипографикаСемейства, кегли и начертания видимого текста — держится ли страница на компактной типографической шкале.
  • ОтступыСколько разных значений padding и gap реально отрендерил браузер.
  • РадиусСколько ненулевых значений border-radius используется у контейнеров и контролов.

git clone https://github.com/AndrewAntoshkin/ds-health.git

npx playwright install chromium

Как устроено

Инструмент открывает страницу в Chromium через Playwright. Берёт видимые элементы и читает стили, которые браузер уже применил. Потом отдаёт баллы, сигналы и рекомендации.

URL → Playwright (Chromium) → getComputedStyle() on sampled elements
→ Count unique colors, fonts, spacing, radii
→ Score each category (0–100)
→ Generate executive summary + priorities + recommendations

Как читать отчёт

Удобный порядок чтения: сначала балл, потом короткий вывод, потом приоритеты, потом сырые значения.

РазделЧто показывает
Общий баллСреднее четырёх оценок. Быстро видно, прошло или нет.
Короткий выводВывод для тех, кто не читает сырые цифры
ПриоритетыЧто чинить первым — с наибольшим эффектом
РекомендацииПрактичные шаги, которые можно поставить в спринт
СигналыОтдельные наблюдения. По ним видно, откуда балл.
Частые значенияСамые частые цвета, размеры и отступы. Их в первую очередь стоит собрать в токены.
Группы похожих значенийПочти одинаковые значения собраны в группы.
