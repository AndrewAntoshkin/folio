Оверлей

spektr

Оверлей спецификации для React. Зажми Alt и наведись на элемент: отступы, типографика и цвета прямо в браузере, как Figma Inspect.

Что видно

Пока идёт замер, оверлей показывает четыре слоя.

  • РамкаСиний контур и размеры: ширина × высота.
  • PaddingЗелёный слой внутреннего отступа.
  • MarginОранжевый слой внешнего отступа.
  • СпекаТипографика, цвета, радиус и параметры раскладки.

Alt+клик закрепляет замер. Повторный Alt+клик снимает его.

Установка

Пакет ставится через менеджер пакетов.

npm install @andrewaitken/spektr

Быстрый старт

Импортируй обёртку и положи в неё любое дерево React.

import { Spektr } from '@andrewaitken/spektr';

function App() {
  return (
    <Spektr>
      <YourApp />
    </Spektr>
  );
}

Только в разработке

Оверлей не нужен в продакшене. Включай его только в dev-сборке.

<Spektr enabled={process.env.NODE_ENV === 'development'}>
  <YourApp />
</Spektr>

Свойства

  • childrenДерево, которое можно инспектировать.
  • enabledВключает и выключает оверлей.
  • SpektrОсновная обёртка. Ловит мышь и рисует оверлей через React Portal.
  • OverlayНижний слой: padding, margin, подпись размеров и тултип спецификации.
  • computeSpecs(el)Снимает визуальные свойства DOM-элемента: размер, шрифт, цвет, радиус, тень, gap.
import { computeSpecs } from '@andrewaitken/spektr';

const el = document.querySelector('.my-button');
const specs = computeSpecs(el);
console.log(specs.fontSize);

Клавиши

  • Alt + hoverИнспектировать элемент под курсором.
  • Alt + clickЗакрепить или снять текущий замер.
  • Отпустить AltСкрыть оверлей, если замер не закреплён.

Примеры

Каждый пример на странице инструмента интерактивный: его можно нажать, переключить и набрать текст, удерживая Alt.

  • КнопкиВарианты с разным padding, фоном, обводкой и радиусом.
  • ТипографикаКегль, насыщенность, line-height и трекинг на шкале.
  • КарточкаАватар, текст и кнопки. Вложенные padding, gap и радиус.
  • ФормаПоле, чекбокс, подпись. Padding, обводка и кегль.
  • БейджиПлотный padding, радиус-пилюля и смысловые цвета.
  • НавигацияФлекс с логотипом, ссылками и CTA. Gap и выравнивание.
  • СписокПовторяющийся ритм, интерактивный переключатель, padding и gap.
