Overlay

spektr

Spektr is a design spec overlay for React. Hold Alt and hover any element to inspect spacing, typography, and colors — like Figma Inspect, but in the browser.

What You See

While you inspect, the overlay draws four layers.

  • HighlightBlue outline with dimensions, width × height.
  • PaddingGreen overlay for inner spacing.
  • MarginOrange overlay for outer spacing.
  • Spec tooltipTypography, colors, border-radius, and layout.

Alt+click pins the inspection. Alt+click again unpins it.

Installation

Install via your package manager.

npm install @andrewaitken/spektr

Quick Start

Import the wrapper and put it around any part of the React tree.

import { Spektr } from '@andrewaitken/spektr';

function App() {
  return (
    <Spektr>
      <YourApp />
    </Spektr>
  );
}

Development Only

The overlay does not belong in production. Turn it on only in the dev build.

<Spektr enabled={process.env.NODE_ENV === 'development'}>
  <YourApp />
</Spektr>

Props

  • childrenThe tree to make inspectable.
  • enabledTurns the overlay on or off.
  • SpektrThe wrapper. It captures the pointer and renders the overlay through a React portal.
  • OverlayThe low-level layer: padding, margin, the dimension label, and the spec tooltip.
  • computeSpecs(el)Reads visual properties from a DOM element: size, type, color, radius, shadow, and gap.
import { computeSpecs } from '@andrewaitken/spektr';

const el = document.querySelector('.my-button');
const specs = computeSpecs(el);
console.log(specs.fontSize);

Keyboard Shortcuts

  • Alt + hoverInspect the element under the cursor.
  • Alt + clickPin or unpin the current inspection.
  • Release AltHide the overlay unless it is pinned.

Examples

Each example on the tool page is interactive: click, toggle, and type while holding Alt.

  • ButtonsVariants with different padding, background, border, and radius.
  • TypographyFont size, weight, line-height, and letter-spacing across a scale.
  • CardAvatar, text, and actions. Nested padding, gap, and radius.
  • FormFields and a checkbox. Padding, border, type size, and label spacing.
  • BadgesTight padding, a pill radius, and semantic colors.
  • NavigationA flex row with a logo, links, and a CTA. Gap and alignment.
  • ListA repeating rhythm with a toggle. Padding, gap, and border.
